1. O 'Vício' da Tabela Externa (Role: Data Engineer)


Em vez de importar (ingestão) todos os dados para dentro do BigQuery de imediato, use External Tables.


Como funciona: O dado fica no GCS (Bucket) em Parquet e o BigQuery apenas 'lê' de lá quando necessário.

Vantagem: Você não paga pelo armazenamento no BigQuery (que é mais caro que no GCS) enquanto está apenas testando queries.


2. Otimização de Custo por Query (Role: Professor)


No console do BigQuery, sempre olhe o canto superior direito antes de dar 'Run'. Ele dirá: 'This query will process X MB when run'.


Evite o SELECT *: Em um banco colunar, isso é o maior erro de iniciante. Selecione apenas as colunas necessárias.

Use Particionamento: Se você filtrar por data em uma tabela de 10GB particionada por dia, o BigQuery lerá apenas os MB relativos àquele dia. O custo cai drasticamente.


3. Terraform como Seguro (Role: Software Engineer)

Mantenha seu terraform destroy engatilhado para qualquer recurso que cobre por tempo (como instâncias de computação, se usar).

1. O Diagnóstico (Software Engineer)


No Linux Mint, ~/Projects pode ser um link simbólico (atalho) para outra pasta, ou você tem duas pastas com nomes quase idênticos (ex: uma começando com maiúscula e outra não). O ls retorna vazio porque, para o sistema, você está em uma 'ramificação' diferente da que o find mapeou.


2. A Solução 'Corta-Caminho' (ENTJ - Direto ao Ponto)


Vamos usar o caminho absoluto que o find nos deu para mover os arquivos para onde o seu VS Code está olhando.


Execute este comando (copie e cole exatamente):


# Força a movimentação do arquivo do caminho que o find achou para a sua pasta atual
mv /home/michael/data-engineering-zoomcamp/03-data-warehouse/homework/*.parquet .


Depois rode:


ls -lh



3. Por que o find vê e o ls não? (Professor)


Isso acontece geralmente por dois motivos:


Caminhos Duplicados: Você pode ter clonado o repo em ~/Projects/ e também ter uma pasta solta em ~/data-engineering-zoomcamp/. O find ~ varre tudo e achou na segunda.

Inconsistência de Shell: O Zsh com Powerlevel10k (seu tema bonitão) às vezes abrevia caminhos, o que mascara onde você realmente está.
