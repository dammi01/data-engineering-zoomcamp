1. O Que é Kestra? (Role: Professor)


Para que serve: É um orquestrador de dados moderno e declarativo (baseado em YAML). Ele automatiza o que você fez manualmente no Módulo 1: baixar o arquivo, processar e subir para a nuvem.

Como instala: No Zoomcamp, usaremos via Docker Compose. Ele subirá o Kestra Server e um banco de dados interno (Postgres ou MySQL) para gerenciar as tarefas.

Diferencial: Você não escreve código Python para o fluxo em si, mas descreve os passos em um arquivo YAML.

id: gcp_taxi_data_ingestion
namespace: zoomcamp

inputs:
  - id: taxi
    type: SELECT
    allowCustomValue: false
    values: ['yellow', 'green']
    defaults: 'yellow'

  - id: year
    type: SELECT
    values: ['2020', '2021']
    defaults: '2021'

  - id: month
    type: SELECT
    values: ['01', '02', '03', '04', '05', '06', '07', '08', '09', '10', '11', '12']
    defaults: '01'

tasks:
  - id: set_label
    type: io.kestra.plugin.core.execution.Labels
    labels:
      file: '{{inputs.taxi}}_{{inputs.year}}-{{inputs.month}}'

  - id: extract
    type: io.kestra.plugin.core.http.Download
    uri: 'https://github.com/DataTalksClub/nyc-tlc-data/releases/download/{{inputs.taxi}}/{{inputs.taxi}}_tripdata_{{inputs.year}}-{{inputs.month}}.csv.gz'

  - id: upload_to_gcs
    type: io.kestra.plugin.googlecloud.gcs.Upload
    from: '{{outputs.extract.uri}}'
    to: 'gs://SEU_BUCKET_NOME_AQUI/{{inputs.taxi}}/{{inputs.taxi}}_tripdata_{{inputs.year}}-{{inputs.month}}.csv.gz'
    serviceAccount: '{{render(vars.GCP_CREDS)}}'
    projectId: '{{vars.GCP_PROJECT_ID}}'

  - id: purge_files
    type: io.kestra.plugin.core.storage.Purge
    executionId: '{{execution.id}}'

Purge: Limpa o armazenamento interno do Kestra para não encher seu disco rígido desnecessariamente.
