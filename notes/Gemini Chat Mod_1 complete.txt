2. O Script de Ingestão (Professor / Engenheiro de Software)
Como você tem pouco tempo até o dia 26, preparei o esqueleto do script de ingestão. O Módulo 1 (2026) exige carregar dois arquivos para o Postgres:

Green Taxi Data (Outubro 2019)

Zones Lookup Table

Crie um arquivo chamado ingest_data.py na sua pasta de trabalho. Este script usa pandas e sqlalchemy. Como você usa o uv, instale as dependências primeiro: uv pip install pandas sqlalchemy psycopg2-binary

Python
import pandas as pd
from sqlalchemy import create_engine
from time import time

def main():
    # Ajuste as credenciais conforme seu docker-compose
    engine = create_engine('postgresql://root:root@localhost:5432/ny_taxi')
    
    # 1. Ingerindo Zones
    df_zones = pd.read_csv('taxi_zone_lookup.csv')
    df_zones.to_sql(name='zones', con=engine, if_exists='replace')
    print("Zones carregadas.")

    # 2. Ingerindo Green Taxi (Outubro 2019)
    # Nota: Este arquivo é grande, o ideal é carregar em blocos (chunks)
    df_iter = pd.read_csv('green_tripdata_2019-10.csv.gz', iterator=True, chunksize=100000, compression='gzip')
    
    for i, df in enumerate(df_iter):
        t_start = time()
        
        # Converte datas (Crucial para as queries do dever de casa)
        df.lpep_pickup_datetime = pd.to_datetime(df.lpep_pickup_datetime)
        df.lpep_dropoff_datetime = pd.to_datetime(df.lpep_dropoff_datetime)
        
        if i == 0:
            df.to_sql(name='green_taxi_data', con=engine, if_exists='replace')
        else:
            df.to_sql(name='green_taxi_data', con=engine, if_exists='append')
            
        t_end = time()
        print(f'Inserido bloco {i}, levou %.3f segundos' % (t_end - t_start))

if __name__ == '__main__':
    main()

Python
import pandas as pd
from sqlalchemy import create_engine
from time import time

def main():
    # Conexão (User: root, Pass: root, DB: ny_taxi)
    engine = create_engine('postgresql://root:root@localhost:5432/ny_taxi')
    
    # 1. Ingerindo Zonas
    df_zones = pd.read_csv('taxi_zone_lookup.csv')
    df_zones.to_sql(name='zones', con=engine, if_exists='replace')
    print("Sucesso: Tabela 'zones' criada.")

    # 2. Ingerindo Green Taxi (Outubro 2019) em blocos
    df_iter = pd.read_csv('green_tripdata_2019-10.csv.gz', iterator=True, chunksize=100000, compression='gzip')
    
    for i, df in enumerate(df_iter):
        t_start = time()
        
        # Converte para datetime (essencial para as questões do homework)
        df.lpep_pickup_datetime = pd.to_datetime(df.lpep_pickup_datetime)
        df.lpep_dropoff_datetime = pd.to_datetime(df.lpep_dropoff_datetime)
        
        if i == 0:
            df.to_sql(name='green_taxi_data', con=engine, if_exists='replace')
        else:
            df.to_sql(name='green_taxi_data', con=engine, if_exists='append')
            
        print(f'Bloco {i} inserido em {time() - t_start:.3f} segundos')

if __name__ == '__main__':
    main()

O erro é claro: password authentication failed for user "root".

Isso significa que o Python conseguiu "bater na porta" do banco (porta 5432), mas o banco recusou a entrada porque a senha ou o usuário não batem com o que foi definido no Docker.

1. O Diagnóstico (Skeptical Expert)
Existem duas causas prováveis:

Divergência no Docker Compose: Você definiu uma senha no docker-compose.yaml (ex: POSTGRES_PASSWORD=postgres), mas o script Python está tentando usar root.

Lixo de Volumes: Se você rodou o Docker com uma senha antes, mudou o arquivo e rodou de novo, o Postgres não muda a senha de um banco que já existe na pasta de dados (ny_taxi_db_data).

2. A Solução Técnica (Step-by-Step)
Passo 1: Verifique seu docker-compose.yaml Abra o arquivo e veja quais são os valores de POSTGRES_USER e POSTGRES_PASSWORD. Eles precisam ser idênticos aos da string de conexão no ingest_data.py: create_engine('postgresql://USUARIO:SENHA@localhost:5432/ny_taxi')

Passo 2: "Reset" Limpo (Recomendado) Para garantir que não há conflito de configurações antigas:

Bash
# 1. Derruba tudo e remove os volumes de dados antigos
docker compose down -v

# 2. Sobe de novo com a configuração fresca
docker compose up -d
Passo 3: Teste de Conexão Manual Antes de rodar o Python de novo, tente entrar no banco pelo terminal para ter certeza da senha:

Bash
docker exec -it <NOME_DO_CONTAINER_POSTGRES> psql -U root -d ny_taxi
(Se ele pedir senha e entrar, a senha está certa. Se der erro de autenticação aqui, o problema é a configuração do Docker).

from sqlalchemy import create_engine

engine = create_engine('postgresql://root:root@localhost:5432/ny_taxi')

df = pd.read_parquet('green_tripdata_2025-11.parquet')

df_zones = pd.read_csv('taxi_zone_lookup.csv')

import pandas as pd
from sqlalchemy import create_engine

def main():
    engine = create_engine('postgresql://root:root@localhost:5432/ny_taxi')
    
    # 1. Ingerindo Zonas (CSV)
    df_zones = pd.read_csv('taxi_zone_lookup.csv')
    df_zones.to_sql(name='zones', con=engine, if_exists='replace', index=False)
    print("Sucesso: Tabela 'zones' criada.")

    # 2. Ingerindo Green Taxi (Parquet - Nov 2025)
    # Parquet já preserva os tipos de data corretamente
    df = pd.read_parquet('green_tripdata_2025-11.parquet')
    
    # Envia tudo para o banco
    df.to_sql(name='green_taxi_data', con=engine, if_exists='replace', chunksize=100000, index=False)
    print(f"Sucesso: {len(df)} linhas de Novembro/2025 ingeridas.")

if __name__ == '__main__':
    main()
