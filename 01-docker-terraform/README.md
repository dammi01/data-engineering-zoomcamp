# Data Engineering Zoomcamp 2026 - Module 1

## Project Objective
Ingest and analyze NYC Taxi data (November 2025) using a containerized environment and Cloud Infrastructure as Code.

## Tech Stack
* **Containerization:** Docker & Docker Compose
* **Database:** Postgres + pgAdmin
* **Infrastructure:** Terraform (Google Cloud Platform)
* **Language:** Python (managed via `uv`)

## Key Features
* Automated infrastructure provisioning (GCS Buckets & BigQuery Datasets).
* Parquet-based data ingestion for performance optimization.
* Network troubleshooting for Linux-based Docker environments.
